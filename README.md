# 🏠 Divisão Justa de Contas do Casal

Uma aplicação web simples, moderna e intuitiva para organizar e dividir as despesas da casa de maneira justa entre o casal mês a mês.

---

## ✨ Funcionalidades

- **Proporção Customizável:**
  - Ajuste por porcentagem livre com slider e atalhos rápidos (ex: 50/50, 60/40, 70/30, 80/20).
  - Modo **"Proporcional à Renda"**: informe a renda líquida de cada um e o app calcula automaticamente a porcentagem justa.
  - Nomes personalizados para os dois participantes (ex: "Você" e "Esposa" ou os nomes reais).
- **Discriminação Individual por Conta:**
  - Mostra em tempo real, abaixo de cada conta, o valor exato que cada um deve pagar daquela despesa.
  - Tabela resumo detalhada no final.
- **Gestão Mês a Mês:**
  - Navegação entre meses (Janeiro, Fevereiro, etc.).
  - Salva automaticamente no navegador (`localStorage`) para não perder nenhum dado.
- **Adição Dinâmica:**
  - Adicione e remova contas livremente (Aluguel, Luz, Água, Internet, Mercado, etc.).
- **Compartilhamento Fácil:**
  - Botão de envio direto formatado para o **WhatsApp**.
  - Botão de **Copiar Relatório** com resumo mensal pronto.

---

## 🚀 Como Executar

Por ser uma aplicação web estática (HTML/CSS/JavaScript puro sem necessidade de build ou servidor):

1. Basta abrir o arquivo `index.html` em qualquer navegador (Google Chrome, Firefox, Safari, Edge, celular, etc.).
2. Ou hospede gratuitamente no **GitHub Pages**:
   - Acesse **Settings** > **Pages** no repositório do GitHub.
   - Em **Source**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`.
   - Clique em **Save**. O link do site ficará no ar em segundos!
